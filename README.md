# BookWorm

A small, responsive reading-list web app. Keep track of books you want to read, are reading, and have finished.

## Features

- Add books with a required title and author, and choose a status: **To read**, **Reading**, or **Finished**.
- See your newest additions first.
- Search by book title or author.
- Change a book's status or remove it from your list.
- See totals for all books, books currently being read, and finished books.
- Keep your list after refreshing the page with browser local storage.
- Use the layout on desktop or mobile.

## Open the app

Open [`index.html`](./index.html) in a modern browser. No build step, server, account, or database is needed.

## Data and privacy

Your book list is saved in local storage in the browser you use. It is not synced to other browsers or devices. Clearing that browser's site data will remove your list. The app does not need an AI service or API key.

The interface loads its fonts from Google Fonts when online and uses system fonts when offline.
